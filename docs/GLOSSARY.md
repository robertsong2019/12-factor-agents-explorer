# 📖 术语表 — 跨项目统一参考

> 各项目教程和文档中使用的统一术语。避免同义混用。

---

## 核心概念

| 统一术语 | 英文 | 定义 | 避免使用 |
|----------|------|------|----------|
| **代理** | Agent | 具有感知-思考-行动循环的 AI 程序 | ~~机器人~~、~~AI助手~~（口语可用） |
| **工具** | Tool | 代理可调用的外部函数，用 `@tool` 装饰器注册 | ~~函数~~（指 Python function 时可用）、~~插件~~ |
| **记忆** | Memory | 代理跨对话保留信息的能力 | ~~缓存~~、~~存储~~ |
| **后端** | Backend / LLM Backend | 大语言模型的接口层 | ~~引擎~~、~~驱动~~ |
| **推理循环** | Reasoning Loop | LLM → 工具调用 → LLM 的迭代过程 | ~~主循环~~、~~事件循环~~ |

## 工具相关

| 统一术语 | 英文 | 定义 |
|----------|------|------|
| **注册** | Register | 将函数声明为代理可用的工具 |
| **调用** | Call / Invoke | LLM 决定使用某个工具并执行 |
| **参数** | Parameters | 工具接受输入的模式定义（JSON Schema） |
| **参数推断** | Type Inference | 从 Python 类型注解自动推断 JSON Schema 类型 |
| **装饰器** | Decorator | `@tool` 语法，将普通函数转为工具 |

## 记忆相关

| 统一术语 | 英文 | 定义 |
|----------|------|------|
| **条目** | Entry | 记忆中的一条记录 |
| **标签** | Tags | 附着在记忆条目上的分类标记 |
| **持久化** | Persistence | 记忆保存到文件（如 JSON） |
| **搜索** | Search | 按关键词或标签查找记忆 |
| **衰减** | Decay | 随时间降低记忆权重 |

## 观测相关

| 统一术语 | 英文 | 定义 |
|----------|------|------|
| **追踪** | Trace / Tracing | 记录代理执行的每一步操作 |
| **跨度** | Span | 一次操作的执行记录（开始/结束/属性） |
| **策略** | Policy | 限制代理行为的规则（如阻止危险操作） |
| **评估** | Evaluation | 对代理执行质量的评分 |

## 架构相关

| 统一术语 | 英文 | 定义 |
|----------|------|------|
| **管道** | Pipeline | 工具按顺序串联形成的工作流 |
| **规划** | Planning | 将目标拆解为多个步骤 |
| **实体** | Entity | 记忆图谱中的节点（人、项目、概念） |
| **关系** | Relation | 记忆图谱中实体间的连接 |

## 写作约定

1. **首次出现** 给出中英对照：`代理（Agent）`
2. **后续使用** 统一用中文：`代理`
3. **代码注释** 统一用英文（与代码语法一致）
4. **API 名称** 保持英文：`memory.add()`, `agent.run()`
5. **标题和列表** 优先用中文，技术名词用英文原文

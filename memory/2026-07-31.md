### Research #040: Graph-Native Agent Memory — From Passive Storage to Living Topology

**Topic**: The shift from "graph as storage format" to "graph as native intelligence substrate" in agent memory systems.

**Papers analyzed (4 key + 3 supporting)**:
1. **HAGE** (arXiv:2605.09942, May 2026) — RL-driven weighted graph traversal. Relation-specific views, trainable edge feature vectors, LLM intent classifier → routing network → query-conditioned traversal. RL joint optimization of routing + edge representations.
2. **HyphaeDB** (arXiv:2606.28781, June 2026) — HNSW topology as multi-agent communication fabric. Agents as nodes with persistent positions. Gossip-based knowledge propagation. Emergent: contradiction detection, pattern crystallization, consensus formation.
3. **GRADE** (arXiv:2606.22741, June 2026) — Dependency vs execution edges for agent traces. Dependency layer predicts failure where run size fails. Leave-one-corpus-out transfer above chance. Generic GNNs misread dependency layer.
4. **When the Tool Decides** (arXiv:2606.14476, June 2026) — LLMs defer to GNN tools 97.6-99.2%. Stronger backbones defer MORE. Selective invocation must be designed in.

**Code prototype**: Query-conditioned weighted graph traversal in TypeScript (~150 lines, zero-dep). Same graph produces different retrieval paths for temporal vs causal vs similarity queries. Verified runnable ✅.

**5 key insights** (added to MEMORY.md as #156-159):
- Graph topology IS the intelligence — validates amg entropy framework
- Dependency edges enable cascading memory correction — 60-line gap no competitor fills
- LLMs rubber-stamp GNN outputs — tools must decide internally (amg already does this)
- HAGE's relation-specific views = multi-perspective retrieval for amg
- HyphaeDB's propagation-through-topology = future multi-agent coordination

**3 new API opportunities for amg**:
1. `conditioned_traverse(entryId, intentProfile)` — ~50 lines + ~40 tests
2. `kind="depends_on"` + `propagate_invalidation(nodeId)` — ~60 lines + ~50 tests
3. `project_graph(relationType)` — ~30 lines + ~30 tests

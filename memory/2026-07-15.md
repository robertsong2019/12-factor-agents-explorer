### Cycle 249: dual-mode binary signature (Hippocampus-inspired SimHash)

**项目**: agent-memory-graph
**分支**: master
**Commit**: c751e9d

**实现内容**:
- `binary_signature(node_id, bits=64)` — SimHash of node text content, 64-bit deterministic bit string
- `hamming_distance(sig_a, sig_b)` — static method, O(1) bit difference counting
- `similarity_search_binary(query, limit, max_hamming, kind)` — fast pre-filter scan with optional kind/max_hamming filters
- `dual_mode_retrieve(query, limit)` — two-phase retrieval pipeline:
  - Phase 1: SimHash candidates ranked by Hamming distance (3× limit candidates)
  - Phase 2: graph retrieve + rerank with combined score (0.4×binary_sim + 0.6×graph_score)
  - Small graph optimization: skip binary phase for <10 nodes (direct retrieve)

**研究背景**: Hippocampus (arXiv:2602.13594) — Dynamic Wavelet Matrix, 31× faster retrieval, 14× fewer tokens。SimHash binary signatures 实现 O(1) 相似度比较，作为 graph traversal 的前置过滤器。

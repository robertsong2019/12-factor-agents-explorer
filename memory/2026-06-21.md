## 20:00 — 深度研究: Agent Memory Security (OWASP ASI06)

**主题**: Agent Memory Poisoning, Integrity, and Production Defense Patterns

**触发**: deep-exploration-evening cron (autoresearch 方法论)

**研究范围**: 15 papers/systems (2024-2026)
- arXiv:2604.16548 (Survey — Memory Lifecycle Framework 6-phase)
- arXiv:2606.04329 (Systematic Study — 9 vulnerabilities, 4 write channels, 6 attack classes)
- AgentPoison (NeurIPS 2024 — ≥80% ASR, <0.1% poison rate)
- MINJA (ICLR 2026 — >95% ASR via bridging steps)
- InjecMEM (61.4% retrieval, 76.6% conditional attack success)
- eTAMP (cross-session, cross-site web agent exploitation)
- A-MemGuard (ICLR 2026 — consensus validation + dual-memory lessons)
- VerificAgent (domain-specific memory verification)
- TierMem (ICLR 2026 Workshop — provenance-aware tiered memory)
- Portable Agent Memory (arXiv:2605.11032 — BLAKE3+Ed25519+DAG)
- MemFlow (arXiv:2603.15125 — Memory Control Flow Attacks)
- OWASP Agent Memory Guard (open-source Python middleware)
- Morris-II Worm (self-replicating prompt via RAG)
- Implicit Memory Bombs (arXiv:2602.08563 — time-bomb via output-reintroduction)
- LangGraph Checkpoint RCE (CSA Advisory — SQL injection → code execution)

**代码**: MemoryIntegrityGuard ~250行 TypeScript, 4-layer defense:
1. Write-Time Provenance (source/trust_level/content_hash/parents[])
2. Retrieval-Time Sanitization (trust-aware filtering, consensus check)
3. Behavioral Monitoring (audit trail, anomaly detection)
4. Recovery (quarantine, trace propagation, restore)

**验证**: 8/8 assertions pass ✅

**关键洞察**:
1. Memory poisoning ≠ prompt injection — ASI06 vs LLM01, temporal decoupling
2. Capability-security tradeoff: aggressive write/retrieval = bigger attack surface
3. Provenance is the missing primitive in ALL production agent memory systems
4. Layered defense > single silver bullet (research consensus)
5. Trust-level DAG propagation: children can't exceed max(parents) trust

**npm 差异化定位**: "Only npm agent memory library with built-in OWASP ASI06 defense"

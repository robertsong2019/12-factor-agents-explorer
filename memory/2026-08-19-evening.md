### 教训（bash set -e 系列）
- `while read` 在管道右侧 = 子 shell，数组修改必丢；先存变量再 `<<<` 喂
- 函数最后一条命令是假值 `&&` 链 → 函数返回非零 → set -e 杀调用方；函数尾 `return 0`
- `(( x -= y ))` 结果为 0 时状态 1 → 用 `x=$((x-y))`
- `"${ARR[@+...}"` 这类嵌套守卫宁可不用：declare 后 + 计数守卫 if 最稳
- awk 引号奇偶扫描 + bash -n 是定位未闭合引号的好组合（报错行 ≠ 病灶行）

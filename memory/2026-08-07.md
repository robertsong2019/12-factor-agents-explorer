### Cycle 373: competitive_spreading() — Lateral Inhibition & Reinforcement (Python code-lab)
- **1 new API**: `competitive_spreading()` — models interference/reinforcement when multiple seeds' activations overlap at shared nodes
- **Two-phase architecture**: Phase 1 runs independent spreading_activation per seed; Phase 2 resolves competition
- **Interference**: Seeds reaching a node via disjoint relations → activation reduced (Anderson & Reder 1999 fan effect)
- **Reinforcement**: Seeds sharing relations → activation boosted (Biederman & Checkoski 1970 redundancy gain)
- **Territory mapping**: Each node assigned to its dominant seed; influence balance metric (Gini-like)
- **6 return structures**: results (with contested flag + dominant_seed), territories, contested, interference log, winners, summary

## 20:00 — Deep Research #057: Long Context vs Agent Memory (autoresearch)

**Topic:** The #1 objection to agent memory systems ("why not just use long context?") — comprehensively answered.

**Method:** Searched 4 angles: cost economics, benchmark data, architectural limitations, alternative approaches (δ-mem).

**Key findings:**
1. **Cost crossover at ~10 turns** (arXiv:2603.04814): Memory systems become cheaper than long-context at ~10 interaction turns. At 20 turns, memory saves 26%. At scale (10K sessions/day), savings exceed 90%.
2. **MemoryArena 50-point gap** (ICML 2026): Models scoring 90%+ on LoCoMo plummet to 40-60% on interdependent multi-session tasks. Retrieval ≠ utilization.
3. **δ-mem third path** (arXiv:2605.12357): 8×8 matrix as parametric memory. Frozen backbone. +31% MemoryAgentBench. Opens a paradigm beyond context and external retrieval.
4. **Lost-in-the-middle persists** in 2026 despite 1M+ token windows. U-shaped curve confirmed across models.
5. **RAG 1,250× cheaper** than long context per query. Memory systems win decisively at production scale.

### 晚间深度研究 #001 (07-02 20:00)
**主题：Graph-Structured Memory for AI Agents**
- 系统性调研 20 篇论文/系统，覆盖 GraphRAG、HippoRAG 2、LightRAG、PathRAG、Zep/Graphiti、Mem0 v3、AriGraph、Memanto、ACON、MemoryArena 等
- 核心发现：
  1. Graph vs Vector 争论收敛于"混合架构 + entity linking"(Mem0 v3 移除了 graph, 用 entity boost 反而达到 SOTA)
  2. MemoryArena benchmark 证明 recall ≠ agency(LoCoMo 95% → MemoryArena 40-60%)
  3. 时间感知(temporal KG)成为标配需求，但 Memanto 无 graph 也达到 SOTA
  4. 遗忘(forgetting)是最被低估的 memory operation
